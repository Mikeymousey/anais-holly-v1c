# Anaïs Holly

One-page site for Anaïs Holly, osteopath in Montreal. Public copy is French. Booking goes to [GoRendezvous](https://www.gorendezvous.com/anaisholly).

## Run locally

```bash
npm install
npm run dev
```

The dev server starts on port 3000 by default. This workspace uses:

```bash
npx next dev --turbopack -H 0.0.0.0 -p 4317
```
